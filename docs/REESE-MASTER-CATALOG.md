# Reese's master catalog brief (Oct 4 2026, 2:16 AM ET)

Rule: the "Game" column names the most recognizable or popular version of each gameplay concept, used as a reference only. The "Hub Version" column says what actually goes into the browser. Never pretend a copyrighted game was copied.

Source hierarchy (best first):
1. EXACT: the original source, released by the copyright holder under a usable licence.
2. FAITHFUL RECREATION: an open-source near-copy (same mechanics, controls and progression) with a licence that permits redistribution, and with its art, sound and names audited.
3. OPEN-SOURCE ALTERNATIVE: an open-source game with the same gameplay.
4. MUST BUILD: an original adaptation, used only when nothing legit is close enough.
Never use pirated, ripped or DRM-stripped copies of proprietary games.

Acceptance filter
- MUST: recognizable; fun to replay; a measurable competitive outcome; can produce a leaderboard; can support a defined giveaway ruleset; works in a browser; can be protected against score manipulation.
- SHOULD: endless or replayable; an existing high-score culture; a short learning curve; works on mobile.
- REJECT: boring; very obscure; no meaningful score; a reskin of another listed game; one-and-done; impossible to validate; needs multiplayer for its core.
- A game does NOT have to be endless. It can use one of these competition types:
  - Endless: highest score, survival, wave, kills, distance or combo.
  - Campaign: cumulative score over a defined set of levels, or fastest completion plus score.
  - Short session: a 60-second or 3-minute score attack, or best of 3 or 5 runs.
  - Strategy: highest wave, total score or economy-adjusted score.

Anti-cheat levels
- L1 simple: the maximum score is obvious.
- L2 session: score, time, progression and maximum rate checks.
- L3 event/action log validation.
- L4 deterministic replay verified on the server.

Metadata card per game: game, category, recognition tier (A+/A/B+), competition type, endless (Y/N), giveaway compatible, scoring, attempts, recommended event length, anti-cheat level, leaderboard, winner rule.
