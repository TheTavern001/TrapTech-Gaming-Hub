## Minimum sign-off evidence

1. Desktop and Android start, play, restart, end, and return-to-Hub flow work.
2. Controls, collision/physics, difficulty, scoring, and all game-over conditions behave correctly.
3. No uncaught exceptions, broken assets, overlapping HUD, mobile viewport overflow, or major frame pacing issues.
4. Score is accepted once only when valid; forged and duplicate scores are rejected server-side.
5. Human reviewer confirms that visual presentation, animation, sound, feedback, and level design meet the Hub's quality bar.
6. Record device/browser, build SHA, date, issue IDs, and retest result before marking PASS.

Automated audit evidence is linked from GitHub Actions artifacts. Automated green is necessary but not sufficient for human gameplay and visual quality sign-off.
