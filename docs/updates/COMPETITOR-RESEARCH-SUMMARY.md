# Competitor Research Summary — Giveaway Gaming Hubs

**Date:** October 18, 2026

## Key Platforms Examined
- **Winify / Winhub:** Creator-first giveaway infrastructure. Provably fair draws, entry collection, persistent hubs. Explicit disclaimer: platform is a venue only and **not responsible for prize fulfillment**.
- **ScopliDrop / Discord giveaway bots:** Task-based entries, referral bonuses, anti-fraud (account age, activity, phone verification), cooldown policies, public listings.
- **Galxe / Zealy / QuestN / Layer3:** Quest/reward platforms. Strong anti-sybil (Humanity Score, wallet history), task verification, leaderboards. Monetization via credentials/points rather than pay-to-win entries.
- **Telegram Mini Apps & Stars Giveaways:** Full-screen games, subscription plans, gift sending. Transparent prepaid draws.

## Common Best Practices
1. **Verifiable randomness** — documented seed or third-party RNG so draws can be audited.
2. **Anti-bot / anti-sybil** — account age, activity requirements, device/IP signals.
3. **Free-to-enter** — no purchase necessary (avoids lottery classification).
4. **Clear liability split** — platform coordinates; sponsor fulfills. Non-fulfillment → blacklist.
5. **Claim window + direct contact** — winner must respond within X days via provided channel.
6. **Engagement loops** — quests/play for cosmetics or achievements, not for cash or entries.
7. **Transparent rules** — eligibility, geo, age, and fulfillment terms shown before entry.

## Hub Advantages to Emphasize
- Skill-based game scores for entries (harder to rig than pure random wheels).
- Pure cosmetic monetization (Hub Credits) — reduces gambling regulatory risk.
- Automated Giveaway Brief + Potato Chat fulfillment path.
- Full admin audit trail and blacklist system.
- Optional brand affiliation that is clearly scoped (Hub-only, no external channel control).

## Recommended Immediate Copy & Process Changes
- Switch all UI text to “Host a Giveaway”.
- Require complete Brief before approval.
- Add Potato Chat link to winner notification.
- Display liability disclaimer prominently.
- Document brand blacklist policy.
- Add trading/sharing options for cosmetics only.
