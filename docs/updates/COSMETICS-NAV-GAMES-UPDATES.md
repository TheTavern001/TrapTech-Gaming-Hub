# Cosmetics, Trading/Sharing, Navigation & Game Library Updates

**Updated:** October 18, 2026

## Cosmetics Enhancement
- Full visual upgrade: custom shaders, animated glow, particle effects, high-DPI assets for avatars, borders, chat badges, skins, frames, titles.
- Avatar system: move beyond “compatibility preview” to real rendered wardrobe where possible.
- Shop, achievements, and profile displays must reflect the enhanced assets.

## Trading & Sharing Model
- **Peer-to-peer cosmetic trading:** Opt-in only, skins/badges/frames (no Credits, no real-world money). Admin can enable/disable globally or per item.
- **Xbox-style sharing:** Users can showcase unlocked cosmetics, badges, and achievements on public profiles or activity feed.
- **Privacy toggle:** Settings → Privacy → Profile Visibility (turn sharing off).
- Credits remain strictly non-tradable, non-withdrawable, cosmetic-only.

Adjust existing 6-tab if preferred, but reduce clutter.

## Game Library Overhaul
- **Layout:** Categorized navigation grid (Cannabis, Evolution, Shooter, Tower Defense, Action, Casual, etc.).
- **Thumbnails:** Uniform high-res 16:9 (or 4K-rendered) cards with hover previews. Majority need full redo.
- **Quality bar:** Every game must reach top-tier polished standards — AAA-style assets, smooth mechanics, good framerate. Cannabis games need unique realistic artwork.
- **Target:** ~500 games covering every category.
- **Sourcing:** Legal open-source / CC0 / distribution feeds only where license allows and scores can be captured for giveaways. Prefer original or fully hosted titles. See HANDOFF + `docs/spec/02-licensed-sources.md`.
- **Immediate fixes (from user playtest):**
  - Hex-stack: restore preferred earlier version
  - Wave games: make upgrades clickable
  - Balloon TD: real difficulty ramp
  - Smashy-style road: only end run when caught by cops (trees/buildings do not kill)
  - Recording, avatar/shop/achievements visual updates
  - Full AAA pass on all games (worst-first per HANDOFF table)
