## 1. Immutable product and governance rules

1. **Exact same baseline for everyone.** All new accounts receive identical default neutral avatar, available in one standardized skeleton; selectable body presentation, skin tone, face and appearance are visual only. Initial equipment, collision boxes, dimensions for gameplay, speed, stamina, physics, health, RNG and scoring are identical. Players unlock changes through normal play and optionally purchase cosmetic rights; purchases never change game mechanics. Owner badges are cosmetic only.
2. **Buyable/earnable objects are cosmetics.** Hats, hair, layered outfits, shoes, glasses, tattoos, makeup, face paint, animations, emotes, pets, trails, vehicle/tool/board/weapon/tower *render skins*, backgrounds, banners, cards and particles. Gameplay must never read `equipped`, `owned`, `paid`, `prestige`, `subscriptions`, `cosmetics` to derive competitive state.
3. **No functional meta power-ups, inventory stacking, gadgets or purchased boost effects.** Audit each existing title's *in-run* power-ups and skill choices separately: user requested removing mechanical power-ups or presenting purely visual effects; deviations need explicit player-fairness signoff before admission. Cosmetic prestige boosts may affect **premium/season cosmetic unlock track XP only**; never player gameplay score, run duration, seed, competitive leaderboard XP, event eligibility, spawn schedule, scoring cap, game attempts or prize probabilities.
4. **All rewards cosmetic/cosmetic-only soft currency or cosmetic progression XP.** No spendable points for prizes, no gameplay upgrades, no transferable balances. Keep soft currency mathematically distinct from purchased currency, cash and official giveaway prizes.
5. **Giveaway authenticity.** Public game scoreboards never equal an official hosted prize contest. Only authorized Trap Tech admin creates/approves official event IDs and game/time/prize rules. Booking, payment verification, and admin approval gate any official event; link sharing or vendor claims alone cannot create one. Signed score sessions, server time, seeded actions, replay/telemetry, abuse limits, idempotent grants, immutable audit trail, refund/chargeback handling and exact tie procedures mandatory.
6. **No clans/guilds or self-promotion.** Friends, non-ranked challenges and genuinely optional multiplayer parties only. No vendor-controlled tournaments, channel spam, advertisements or outbound community promotion; harden content moderation/permissions.
7. **21+ age gate** and admin-only protected operations; 2FA and long hidden admin path; never claim browser source can be hidden from devtools. Personal user identity stays private; public brand is the existing slim crowned twin-T Trap Tech logo, not a new logo. Single Deplexo app, optional later PWA/Android packaging.
8. **Source rights before shipping.** Prefer externally authored, commercial-compatible, licence-proven assets/models/animations/UI/audio. Own stylized integration and branding, not unlicensed clones of proprietary games. Verify code, art, fonts, music and model rights separately. Keep original mechanics inspiration recognizable while producing an independently licensed game.
9. **No automatic deployments.** All commits on an isolated branch; five *manual* release checkpoints; regression/local build and smoke PASS required before host changes. Never delete old player DB or Deplexo app to clear deployment cards. Preserve chronological SHA-level log, failure cause and resume point.

## 4. QA definition of done per visible game

- **Identity/mechanics:** credible reference loop and unique inputs, objectives, hazards/AI and survival/failure rules; documented why non-duplicate; seeded scoring/competitions.
- **Technical:** all 5-minute/30-minute/endless soak runs, keyboard/touch/gamepad, variable FPS, pause/resume, navigation/visibility, restart, replayability; zero uncaught console errors, memory bounded, no event or score forgery.
- **Art/audio:** properly licensed model sources with PBR/animations/texture sizes, real thumbnail, readable phone HUD; motion/reaction feedback with optional mute and reduced motion, distinct character/vehicle visual shape.
- **Performance:** 60 fps target on capable Android/desktop, P95 <= 16.7 ms where measured, adaptive LOD/DPR, >=720p rendering target when device allows, higher resolution desktop where reasonable; degrade gracefully rather than stutter. Record target hardware, GPU, resolution and logs; desktop 4K support is not a guarantee of 4K on every phone.
- **Approval:** screen recording & screenshots + measured p50/p95 + licence hash + server-backed score/cheat negative + human owner review. **Blocked/unknown is not PASS**. QA labels are `SOURCE_ONLY`, `DEVICE_TESTED`, `OWNER_APPROVED`; each requires the prior level.
