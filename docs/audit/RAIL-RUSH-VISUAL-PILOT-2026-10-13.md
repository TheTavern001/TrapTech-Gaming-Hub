# Rail Rush 3D source-based visual upgrade — 2026-10-13
Owner physical Android screenshot demonstrates a bulky procedural box-train crowding the view and partially clipped score HUD. The shared runner already loads five Kenney CC0 train GLBs but rendered rounded boxes instead. On this **isolated non-deploy branch**, visual trains now use the existing five packaged CC0 glTF meshes with uniform auto-orientation/scale. Hitboxes (9.5m × 2.3m × 3m per car), score, speed, patterns, seeded difficulty and leaderboard remain unchanged. Mobile chase camera moves back and number strings fit within HUD panels. GLB byte counts and canonical git blob SHA1 are pinned in `tools/test-runner-train-assets.js`.

This is a graphical PILOT, not AAA art/animation acceptance or proof of 60fps on Samsung. Source train meshes may still be low polygon; town scenery is still procedural, and entire 93-game redesign remains pending.
