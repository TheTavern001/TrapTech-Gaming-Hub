# Gaming Hub game candidates

Research-only candidate list for static, client-side browser games. The first import batch was cancelled; no games were excluded for that reason. `docs/LAB-BATCH-1.md` was absent when checked.

## Scope and verification

- 121 finished HTML5/JS games with public demo links are listed. Demo links were opened with `curl -L` or WebFetch on 2026-10-04 (ET); a successful page response is recorded as “verified” below. A page loading does not replace a manual play-through before import.

- Root `LICENSE`, `LICENSE.txt`, or `LICENSE.md` was checked for every repository and is called out in the licence column. Only MIT, BSD, Apache-2.0, CC0, GPL, and compatible OFL sub-assets are included; no NC or unlicensed repository was intentionally included.

- “Phone-ready?” is a conservative integration estimate, not a claim that every control already works on touch. “easy” means an endless scoring wrapper/seed ladder is straightforward; the hub should use a numeric score with no ceiling.

- Art/audio caveat: when a repo bundles media or uses contributor assets, the notes explicitly require an asset-level provenance check or replacement. Procedural/CSS/DOM-only art is preferred.

- The requested range batch 2–6 provides 100 rows; the >=120 requirement requires batch 7, which is included as a 21-row overflow.
