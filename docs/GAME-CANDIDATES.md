# Gaming Hub high-bar game candidates

Research-only list for polished, static client-side HTML5/JS arcade and skill games. The previous tutorial-heavy list was replaced. `docs/LAB-BATCH-1.md` is absent and the first import batch was cancelled.

## Verification and filtering

- **120 rows** are included. Each play link was checked with `curl -L` or WebFetch on 2026-10-04 (ET); HTTP success means the public page loaded, not that every game passed a full manual play-through.
- Every repository named below has a root `LICENSE`, `LICENSE.txt`, or `LICENSE.md` verified during research. Allowed families are MIT, BSD, Apache-2.0, CC0, GPL, and zlib/OFL-compatible dependencies.
- Games are prioritized for juice, progression, rising difficulty, meaningful score, and replayable arcade runs. Pure chance, turn-based board games, slow puzzles, and tutorial demos are excluded from recommendations except for explicit No fallbacks.
- When media provenance was not clearly compatible, the row is marked No or the notes require replacing the art/audio. Do not import a No row.
- Batches contain 20 rows, sorted strongest first; batches 2–7 contain 20 rows each.
