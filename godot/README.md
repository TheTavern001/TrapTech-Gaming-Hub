# Trap Tech Gaming Hub — Godot Rebuild

Open this in Godot 4.3+ right now. It is playable.

## How to open (do this in ~30 min)
1. Pull the latest on branch `godot-hub-start`.
2. Godot → Project → Import → select `godot/project.godot`.
3. Press F5.

## What you will see
- Dark hub with title.
- Play Example Game button.
- Game grid with three cards (all currently load the same simple endless tap game).
- In the game: hold/click to rise, release to fall, dodge red bars. Score increases as you pass them. Click after game over to return.
