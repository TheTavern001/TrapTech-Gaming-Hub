# Rift Survival

Original arena-survival game built for The Gaming Hub.

- Code: original Hub game code using the shared Kit engine.
- Visuals: original Canvas 2D vector art rendered at runtime.
- Audio: synthesized sound effects from the shared Hub engine.
- Third-party assets and commercial-game trademarks: none intentionally included.

This is an original work in the arena-survival genre, not a port or copy of a named title.
