# Neon Circuit

Original endless arcade racer created for The Gaming Hub (Trap Tech Solutions).

- Code: original Hub code, MIT.
- Visuals: original vector art drawn at runtime using Canvas 2D.
- Audio: synthesized by the shared Hub engine using WebAudio.
- Third-party game art, music, and trademarks: none intentionally included.

Inspired by the general arcade-racing genre; not a reproduction of a named commercial game.
